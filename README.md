# TeleExam AI Backend

This repository contains the high-performance FastAPI monolithic backend that powers the TeleExam platform. It provides endpoints for users, AI tutoring sessions, and administrative controls.

## Running Locally

```bash
uvicorn app.main:app --reload
```
